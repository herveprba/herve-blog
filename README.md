# Herve's Blog 📝

A simple personal blog project built with pure HTML. This project is part of the **Complete Intro to Web Development v3** course by Brian Holt, created to practice the fundamentals of HTML.

## 📖 Description

This project is a static personal blog consisting of two main pages: a home page containing blog posts, and an "About Me" page containing information about the author. The blog is built without CSS or JavaScript, focusing purely on learning basic HTML structure and elements.

## 🗂️ Project Structure

```
herve-blog/
├── index.html      # Home page with intro and blog posts
├── about.html      # About the author page
└── README.md       # Project documentation
```

## 📄 Pages

### 1. `index.html`
The main blog page, which contains:
- **Blog title** — Herve's Blog
- **Navigation link** to the About Me page
- **Introducing Myself** — a short introduction about the author
- **5 Blog Posts** — each post includes:
  - Post title
  - Author name
  - Publication date
  - Post content
  - An illustrative image (from [Picsum Photos](https://picsum.photos))

### 2. `about.html`
The "About Me" page, which contains:
- **Blog name** — Herve's Blog (linked back to the home page)
- **A few paragraphs** about the author
- **A list of accomplishments** from the author

## 🛠️ Technologies Used

- **HTML5** — web page structure

## 🚀 Getting Started

1. Clone or download this repository:
   ```bash
   git clone <repository-url>
   ```
2. Open the project folder.
3. Open `index.html` in your favorite browser (Chrome, Firefox, Edge, etc.).
4. Navigate between `index.html` and `about.html` using the available links.

## 📌 Project Requirements

This project was built based on the following requirements:

- [x] The blog has two pages: `index.html` and `about.html`
- [x] `index.html` has a title and a quick intro
- [x] `index.html` has a link to `about.html`
- [x] The blog has 5 posts on the same page
- [x] Each post has a title, an author, a date, and post text
- [x] Posts include images (bonus points ✨)
- [x] `about.html` contains the blog name, paragraphs about the author, and a list of accomplishments
